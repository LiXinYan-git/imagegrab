为什么需要它

详情页的图片，本来不该这么难存

商品图分散在轮播、详情长图和缩略图里，还常常是懒加载；手动右键一张张保存既慢又容易漏。

图片分散，容易漏

主图、细节图、长图、SKU 图分布在不同区域，滚动加载后更难一次找全。

格式不统一

jpg、webp、png 混在一起，后续上传、归档或做图时需要统一格式。

手动保存太慢

几十张图逐张右键另存，重命名还要一张张来，效率很低。

适配平台 淘宝 / 天猫 京东 拼多多商家版 Chrome / Edge
核心功能

从提取到保存，一步到位

点击一次按钮，剩下的扫描、过滤、预览、转换和下载都由插件完成。

一键提取

自动扫描 <img>、srcset、data-src 等懒加载属性以及背景图。

智能过滤

自动排除 logo、图标、头像、占位图、1×1 像素图，以及小于 100×100 的小图。

集中预览

新标签页网格展示全部图片，附序号与尺寸，按面积从大到小排列。

自由勾选

支持全选、反选、清空，顶部实时显示已选数量，只下载需要的图片。

统一 PNG

jpg / webp / png 统一用 Canvas 重新编码为 PNG，避免格式混杂。

批量下载

一键保存到默认下载目录，文件名 商品图_001.png 自动编号，并显示进度与结果。

安装步骤

四步装进浏览器，全程不到一分钟

插件以「开发者模式」加载，无需上架商店，也无需注册账号。

  1. 1

    下载并解压插件

    把插件文件夹（包含 manifest.json 的那一层）保存到本地任意位置。

  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    打开页面右上角的 开发者模式 开关。

  4. 4

    加载已解压的扩展程序

    点击 加载已解压的扩展程序，选择插件文件夹即可。

Edge 用户：地址栏输入 edge://extensions，开启「开发人员模式」后选择「加载解压缩的扩展」。
